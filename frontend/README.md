# Frontend (Module 4)

React + Vite dashboard. Create the app inside this folder:

```bash
cd frontend
npm create vite@latest . -- --template react
npm install
npm run dev        # http://localhost:5173
```

The backend allows CORS from `http://localhost:5173`.
